Overview

DistFS is an ongoing systems project focused on building a distributed file storage layer from the ground up. The goal is a filesystem that survives node failures without losing data or availability — something I'd eventually trust to store my own files.

The core of the project is a set of storage primitives: chunked file storage across multiple nodes, replication so no single node failure loses data, node coordination for tracking which replicas hold which chunks, and failure detection/recovery to re-replicate data when a node drops out. Metadata (file → chunk mappings, replica locations) is kept consistent across the cluster even as nodes join, leave, or fail.

This is very much a learning-by-building project — it's my way of getting hands-on with the distributed systems concepts (consensus, replication, failure detection) that I first got interested in through coursework at Michigan.
