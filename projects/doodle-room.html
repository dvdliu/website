Overview

Doodle Room is a real-time collaborative whiteboard built with Java WebSockets on the backend and vanilla JavaScript on the frontend. I built it to actually use with friends — for taking shared notes and doodling during class — rather than as a purely academic exercise.

It supports synchronized drawing across multiple connected clients, live cursor tracking so you can see where everyone is on the canvas, and shared canvas state replay so a late joiner sees everything drawn so far instead of a blank board. The multi-user collaboration model is loosely inspired by skribbl.io.
