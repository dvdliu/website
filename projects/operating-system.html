Overview

This project is a mock operating system built in C++, originally started as a class assignment for a University of Michigan operating systems course and later expanded into a larger personal systems project.

It implements a custom user-level thread library (scheduling, context switching, synchronization primitives), a virtual memory pager that manages page tables and handles page faults, and a networked file system layered on top. Building each piece from scratch — rather than just reading about how they work — is what got me hooked on systems programming in the first place.
