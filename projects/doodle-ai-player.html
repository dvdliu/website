Doodle Room AI Player

An AI player for Doodle Room's Pictionary game — it joins as a regular WebSocket player and plays both roles: guessing sketches from a live canvas snapshot, and taking its own turn by asking Claude to plan and draw a sketch stroke by stroke.

Python Claude API WebSockets AI

Overview

This is a standalone bot that connects to a running Doodle Room PictionaryServer exactly like a human player would — no changes to Doodle Room's own code — and plays the full game on both sides of the board.

As a guesser, it replays the drawer's stroke events onto a virtual canvas, periodically hands a snapshot to Claude's vision, and sends its best guess as a chat message — pacing itself with cooldowns, backing off once it guesses correctly, and avoiding guesses other players already tried. As the drawer, it asks Claude to design a simple line-art sketch of its word as a JSON stroke plan, then executes that plan as real timed DRAW events, budgeted to fit inside the turn's clock.

Both roles boil down to the same idea in opposite directions — one call turns pixels into a word, the other turns a word into pixels — wrapped in a small state machine that tracks turns, scoring, and timing from the server's messages.

Tech Stack
Python (asyncio) websockets Anthropic API (vision + generation) Pillow pytest
